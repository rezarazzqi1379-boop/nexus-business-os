# NEXUS Adapter Routing Matrix v1 — 2026-10-07
Goal: durable routing policy, not permanent sessions. Adapters are invoked when a measurable task matches their proven role.
- GitHub: ACTIVE_CORE — code/state/CI. Authority: reproducible implementation/test evidence only.
- Exa/Search: ACTIVE_DISCOVERY — live web discovery/document hunting. Never authority by itself.
- Files/Project Sources: ACTIVE_CORE — canonical source recovery and project evidence.
- Notion: ACTIVE_STATE — operational state persistence/read-back. Custom Agents: BLOCKED_ENTITLEMENT (Business plan required), so no dependency.
- Google Drive: ACTIVE_EVIDENCE — durable master/evidence persistence/read-back.
- HubSpot: CONNECTED_READ_VERIFIED — COMPANY/CONTACT/DEAL/TASK etc readable; writes exist but remain human-gated. Use CRM reads only when conversion candidates survive evidence gates.
- Apollo: CONNECTED_CATALOG_VERIFIED — tool catalog callable. Paid search/enrichment requires exact credit confirmation; default to free lookup when available. No paid calls performed.
- ABRAMS Trade Intelligence: ACTIVE_DISCOVERY_BENCHMARK — HS/trade/buyer discovery. HS7228 data snapshot is 2024 and therefore historical discovery context, not current demand. Exact 42CrMo4 classification requires post-forging-working clarification; no guess.
- LinkedIn: CONDITIONAL_PERSON_LOOKUP — only after a surviving named company needs decision-function verification; not broad prospecting.
- Semrush: HOLD_NO_CURRENT_GAP — SEO/traffic intelligence does not solve current tender/stock/eligibility bottleneck.
- PostHog: HOLD_NO_TELEMETRY_NEED — activate only when NEXUS product telemetry/experiment measurement exists.
- Open Contracting GitHub candidates: BENCHMARK_ONLY — pilot only if target publisher OCDS coverage + incremental qualified evidence passes procurement_adapter_gate.
Permanent means policy/routing persistence and repeated testable invocation, not an always-running hidden process.
