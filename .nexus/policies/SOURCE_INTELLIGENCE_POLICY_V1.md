# NEXUS Source Intelligence Policy v1 — 2026-10-07
Purpose: optimize verified commercial evidence, not search volume.
Authority axis: canonical/project master > primary buyer/procurement/official technical source > reproducible trade/public evidence > marketplace/aggregator > AI/search snippet.
Freshness axis is independent: a primary source can still be historical for a dynamic claim.
Reproducibility axis is independent: a prior claim that cannot be reproduced is CLAIM_REVALIDATION/HOLD.
Yield metric: unique qualified evidence / raw hits. Mirrors and duplicates count once.
Cost metric: credits, latency, manual review and integration maintenance.
Rules:
- Never promote a low-authority source because it has many hits.
- Never use stale primary evidence as current/open demand.
- Search/Exa are discovery adapters, not authority.
- Aggregators may discover candidates; primary/independent evidence should bind consequential fields when available.
- GitHub project popularity/activity does not justify integration; measured coverage + incremental qualified evidence + maintenance case are required.
- Every source-family promotion/demotion must be reversible and supported by a measured cycle report.
