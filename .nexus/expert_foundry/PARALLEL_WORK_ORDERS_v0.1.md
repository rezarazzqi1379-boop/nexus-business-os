# Expert Foundry Parallel Work Orders v0.1

These work orders are bounded preparation tasks. They do not authorize merge,
deployment, live plant control, external outreach or knowledge promotion.

## Work Order A — ChatGPT NEXUS Research Architecture

Read `.nexus/state/CURRENT_STATE.md`, the Expert Foundry design and master
prompt first. Build a source-class and terminology map for the first metallurgy
proof without yet making process recommendations. Define the primary research,
standards, patents, manufacturer documents, plant measurements, lab results and
tacit-experience sources required. Produce a claim-gap matrix, source-selection
criteria, retraction/supersession procedure and a research update cadence.
Preserve authority conflicts. Do not contact people, access login-walled sources
without authorization, or publish conclusions. Return exact evidence locators,
unknowns and the next bounded research question.

## Work Order B — Codex Knowledge Core

Fetch first and read `.nexus/state/CURRENT_STATE.md`. Review
`expert_foundry.py` and its tests on the assigned branch. Test validation,
hash-chain integrity, tamper detection and non-overwriting snapshots. Propose
the smallest compatible integration with the unmerged `research_evidence.py`,
`research_lab.py` and Coordination Kit branches. Do not duplicate their routing,
research-run or handoff formats. Do not merge or deploy. Return exact clone,
branch, base, HEAD, Python executable, diff, test commands, exit codes,
integration conflicts and one recommended vertical proof.

## Work Order C — Claude Code Independent Review

Fetch first and read `.nexus/state/CURRENT_STATE.md`. Independently review the
Expert Foundry branch for unsafe self-promotion, unverifiable experience,
cross-project contamination, mutable-history risks, stale-environment claims,
missing failure cases and overlap with existing research/coordination branches.
Run focused and full regressions with `.venv/Scripts/python.exe`. Treat every
nonzero exit as non-pass. Do not modify the implementation in the review pass.
Return findings ordered by severity with exact file/line evidence, followed by
tested strengths, unknowns and the smallest corrective work order.

## Work Order D — Independent Domain Reviewer

Review only the proposed knowledge categories, experience-capture protocol,
hypothesis discipline, experiment gate and competence metrics. Challenge the
assumption that more stored information creates expertise. Identify missing
mechanistic reasoning, applicability checks, data-quality controls and blind
evaluation cases. Do not accept AI agreement as evidence and do not propose a
production recipe. Return a bounded rubric usable by a metallurgist reviewer.

## Reconciliation owner

ChatGPT NEXUS receives all four outputs and separates FACT, MEASUREMENT, CLAIM,
EXPERIENCE, HYPOTHESIS and UNKNOWN. It preserves disagreements and produces a
single change proposal. Reza approves any protected action or tie-break decision.
