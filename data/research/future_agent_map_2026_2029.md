# NEXUS Future Agent Map 2026-2029

Status: RESEARCH + INVENTION PROGRAM. This document separates observed facts from hypotheses. It grants no production authority.

## Current evidence-backed direction

FACT — Agent runtimes are moving toward controlled sandboxes, long-horizon execution, sessions/memory, tracing and MCP-enabled tools.
FACT — MCP 2026-07-28 moved to a stateless core with routable headers, cacheable catalogs, task extensions and stronger authorization semantics.
FACT — Agent control planes are emerging as a distinct layer above harnesses and runtimes, emphasizing policy, observability, budgets and multi-agent orchestration.
FACT — Stateful/persistent-agent work is increasingly focused on reusable memory, experience trajectories and skill learning rather than prompt-only persistence.

## NEXUS prediction map

### 1. Persistent executive agents — NOW/NEAR
Prediction: agents will retain identity, project state, skills, decision history and work queues across machines and sessions.
Build now: canonical authority + durable state + versioned memory + exact action gates + replayable event ledger.

### 2. Experience-learning agents — NEAR
Prediction: strong agents will learn from normalized trajectories and propose their own versioned skill/memory updates.
Build now: trajectory ledger, evaluator, skill proposal format, regression replay, rollback. No uncontrolled self-modification.

### 3. Agent mesh / protocol identity — NEAR
Prediction: organizations will use heterogeneous agents from several vendors. Identity, capability negotiation and authorization will matter more than one framework.
Build now: vendor-neutral agent identity, capability manifests, MCP/A2A adapters, per-project policy envelopes, budget and data-classification boundaries.

### 4. Computer-use + sandbox-native agents — NOW/NEAR
Prediction: agents will increasingly operate real workspaces, browsers, terminals and enterprise applications rather than only call APIs.
Build now: disposable workspace profile, network/secret boundaries, action receipts, screenshot/evidence capture, replay and reset.

### 5. Business world models — MID
HYPOTHESIS: business agents will simulate supplier failures, market changes, logistics, pricing and engineering scenarios before recommending actions.
Build precursor now: temporal evidence graph, explicit assumptions, uncertainty labels, counterfactual evaluation and outcome ledger.

### 6. Autonomous business/engineering scientists — MID
HYPOTHESIS: agents will generate hypotheses, design experiments, retrieve evidence, run bounded tests and update governed knowledge continuously.
Build precursor now: hypothesis registry, experiment contract, reproducibility gate, critic/evaluator and evidence-backed knowledge proposal.

### 7. Company digital twins — MID/LONG
HYPOTHESIS: mature firms will operate a versioned digital operational twin covering projects, counterparties, assets, workflows and decisions.
Build precursor now: stable IDs, event ledger, provenance, entity graph, process state, access controls and replay.

### 8. Self-composing tool ecosystems — MID
HYPOTHESIS: agents will assemble temporary toolchains and subagents for each problem instead of relying on static workflows.
Build precursor now: Capability Forge + Agent Catalog + MCP Broker + sandbox admission + measured adoption gate.

### 9. Autonomous negotiation and commerce — MID/LONG
HYPOTHESIS: agents will negotiate commercial terms and execute bounded transactions under policy, escrow/budget and exact approval limits.
Build precursor now: negotiation memory, concession ledger, authority limits, exact payload binding and transaction simulation. No autonomous payment/order authority today.

### 10. Physical/embodied enterprise agents — LONG
HYPOTHESIS: software agents will coordinate robots, machines, inspection systems and production equipment through governed digital interfaces.
Build precursor now: device capability manifests, simulation-first control, fail-safe boundaries, telemetry provenance and human override.
