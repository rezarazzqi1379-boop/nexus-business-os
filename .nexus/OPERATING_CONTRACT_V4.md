# NEXUS Operating Contract v4 — Discovery Fabric

Status: IMPLEMENTED ON FEATURE BRANCH
Extends: v3. v3 remains immutable historical contract.
Promotion: TESTED/ACTIVE/PRODUCTION requires CI evidence and normal gates.

## Mission
Evolve NEXUS from performing discovery into measuring and improving discovery itself:
Sense → Generate Paths → Search → Verify → Contradict → Connect → Score → Measure → Learn → Distill → Invent.

## Discovery Fabric
All discovery providers expose source identity, evidence references, cost, latency and outcome. Provider failure must not silently become negative evidence.

## Strategy portfolio
For each product/application/market generate independent paths: application-first, trade/HS reverse discovery, competitor/customer reverse discovery, project/equipment decomposition, tender/procurement, and demand-signal paths. Preserve provenance per hop.

## Discovery Method Graph
Measure each method by coverage, precision, accepted results, false positives, false-negative cases, evidence quality, cost and latency. Promotion requires measured incremental value.

## Exploration / exploitation
Keep proven methods and experimental methods separate. Novelty alone is not improvement. New capabilities remain experimental until benchmarked against a baseline under comparable budget.

## Query evolution
Store query, language, source, market, application, results, qualified results, false positives, cost, latency and downstream outcome. Generate multilingual industrial query variants without assuming translated grade equivalence.

## Evidence triangulation and contradiction
Important commercial claims should seek independent evidence and contradictory evidence. Distinguish NO_EVIDENCE / NEGATIVE_EVIDENCE / CONTRADICTORY_EVIDENCE / STALE_EVIDENCE / SOURCE_UNAVAILABLE / NOT_CHECKED. Copied sources are not independent corroboration.

## Coverage
Track Country × Industry × Application × Product × Buyer Type × Source Type × Discovery Method. Blind cells are first-class backlog items.

## Signal fusion / temporal intelligence
Weak signals remain individually traceable when fused. Track first_seen, last_seen, observed_at, changed_at, evidence age and trend. Historical evidence never silently becomes current state.

## Buyer universe
Build and deduplicate candidate universes before paid contact enrichment: candidate → evidence-qualified → application-qualified → dimension-qualified → trade-qualified → tier → contact candidate.

## Decision makers / competitors
Buying committees keep role, influence and contact confidence separate. Competitor-customer relationships remain hypotheses until evidenced.

## Ensemble
Application, Trade, Company Research, Demand Signal, Competitor, Product Fit, Compliance and Contradiction components may disagree. Preserve dissent; do not force consensus.

## Benchmark / ablation
Maintain known buyer/non-buyer/competitor/distributor/end-user/hard-case benchmarks. Measure precision, recall, evidence coverage, cost, latency, FP/FN. Compare Baseline vs Baseline+Capability under comparable budget.

## Failure autopsy
Classify discovery misses: SOURCE_GAP / QUERY_GAP / LANGUAGE_GAP / ONTOLOGY_GAP / TRADE_DATA_GAP / APPLICATION_MAPPING_GAP / ENTITY_RESOLUTION_FAILURE / DEDUP_FAILURE / STALE_EVIDENCE / BAD_SCORING / FALSE_NEGATIVE / PROVIDER_FAILURE / COST_GATE / COMPLIANCE_FILTER / UNKNOWN. Repeated misses become regression cases.

## Source Discovery lifecycle
DISCOVERED → IDENTIFIED → LICENSE_CHECKED → TOS_CHECKED → SECURITY_CHECKED → DATA_QUALITY_CHECKED → SANDBOXED → BENCHMARKED → EXPERIMENT_ONLY → APPROVED_PROVIDER → ACTIVE.
Never attach credentials to unreviewed sources.

## Skill evolution / memory
OBSERVED → REPEATED → DISTILLED → TESTED → BENCHMARKED → APPROVED → REUSABLE. Store reusable procedures, not unbounded raw traces. Human corrections create correction evidence and regression candidates, not automatic global rules.

## Economics
Track cost per accepted result, qualified lead, verified decision maker, RFQ, accepted opportunity and order. Optimize outcomes, not call volume.

## Discovery Scientist
May discover gaps, propose methods, implement reversible experiments, benchmark and recommend promotion/rollback. Cannot spend paid credits, send externally, merge, deploy production, change credentials or accept terms.

## Cycle completion
A discovery cycle reports what/where/how was searched, sources covered, evidence/contradictions, blind cells, method performance and next safe action; then starts the highest-value safe action.
