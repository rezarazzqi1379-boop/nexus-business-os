## New relationship rules
1. Award/winner data creates an INCUMBENT edge, not an endorsement.
2. Repeated tenders create a BUYING_PATTERN edge, not CURRENT_DEMAND unless a live event exists.
3. EPC contract creates a PROCUREMENT_INFLUENCE path; it does not prove the end user buys the component directly.
4. Technical-document requirement creates TECHNICAL_GATE evidence.
5. Delivery location creates SITE linkage only when the procurement source binds it.
6. Bidder lists can seed competitor/supplier discovery, but losing bidders are not incumbents.
