# NEXUS v3 Capability Roadmap

## P0 — close current regression
- ProjectMemory append-only supersession CI green.
- Preserve idempotent trade ingestion and Apollo spend-gate tests.

## P1 — revenue/evidence spine
- Opportunity Graph schema + evidence-backed edges.
- Demand Signal record + freshness/need linkage.
- Reverse Buyer Discovery query/result contract.
- Country Agent opportunity queue.
- Buyer Fit / Strategic Value / Spend Confidence orchestration.

## P2 — commercial learning
- Commercial Genome feature schema and deterministic similarity baseline.
- Deal Room schema.
- Outcome + Lost Deal taxonomy.
- Experience distillation into hypotheses/lessons/playbooks.

## P3 — evolution engine
- NEXUS Scientist experiment contract.
- Held-out eval sets and regression gates.
- Cost/latency/outcome telemetry and Agent Health.
- Candidate promotion validator and rollback evidence.

## P4 — external adapters
- Official trade provider adapter(s), then validated aggregators as fallback.
- Apollo free resolver before paid enrichment.
- CRM/outreach adapters remain preparation-only until human gates.

Principle: mechanize stable rules in code; keep uncertain commercial judgments evidence-linked and reversible.
