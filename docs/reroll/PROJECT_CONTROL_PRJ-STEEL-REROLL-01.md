## ۰. قاعدهٔ جداسازی

- این پروژه مستقل است. داده‌های پروژه‌های قوطی‌سازی، هیدروتست، عملیات حرارتی لوله و دیگر پروژه‌ها وارد آن نمی‌شوند.
- **تنها ارجاع مجاز به PRJ-STEEL-ROLLING-LINE-01 گزینهٔ C است**، یعنی «استفاده از خط موجود»، و فقط با وضعیت واقعی ثبت‌شدهٔ آن پروژه. آن تجهیزات هیچ‌وقت به‌صورت خودکار وارد طراحی این پروژه نمی‌شوند.
- کد محاسبه `reroll_study.py` است. این فایل فقط توابع فیزیکی عمومی را از `slab_line_design.py` وام می‌گیرد، مثل تنش سیلان، طول تماس، Wusatowski و افت حرارت. همهٔ ورودی‌های پروژه، یعنی ابعاد، غلتک، سرعت و دما، صریحاً از این پروژه می‌آیند.
