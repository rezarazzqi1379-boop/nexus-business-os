# NEXUS Conversion Lab — staged execution design v1
1. SIGNAL — current/open named buyer evidence only.
2. BIND — bind source/date/status/product/geometry/spec; deduplicate mirrors.
3. TECHNICAL — exact standard/edition, chemistry/mechanics, HT/condition, NDT, certification, tolerances.
4. CAPABILITY — source-backed producer capability; never stock.
5. STOCK — fresh 11-field evidence only.
6. ELIGIBILITY — supplier registration/PQR/origin/local-content/financial/experience.
7. RELATIONSHIP — exact producer-buyer relationship evidence.
8. CONVERSION — EVIDENCE_READY only if all required layers reproduce.
9. RED TEAM — attack each promotion edge; successful attack becomes regression.
10. MEASURE — unique qualified signals, false positives prevented, time/cost, technical accepts, stock-confirmed fits, EVIDENCE_READY.
11. PERSIST — GitHub evidence/code + CI; Notion operational state; Drive durable master; read-back.
12. LEARN — promote only measured winning patterns; generate next prompt from bottleneck.
