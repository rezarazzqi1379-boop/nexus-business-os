Load GLOBAL_KERNEL first, then only the smallest relevant stage.

S0 RECOVERY — recover Registry/Master/project_id/repo/CI/adapters/latest graph; fail closed on ambiguity.
S1 CLUE INGEST — capture typed clue + provenance + time + evidence class; no inference promotion.
S2 ENTITY RESOLUTION — aliases/domains/IDs/people/spec editions; fuzzy match routes review only.
S3 THREAD FUSION — connect independent clues; score verification priority; deduplicate mirrors.
S4 HYPOTHESIS — statement + falsifier + required evidence + expected value + cost.
S5 PRIMARY DOCUMENT HUNTER — controlling spec/BOQ/PQR/award/certificate/inspection/source.
S6 TECHNICAL CROSSWALK — exact standard/edition/chemistry/mechanics/process/HT/NDT/tolerance/certification.
S7 COMMERCIAL GRAPH — current demand/award/trade/competitor/PQR/CRM/person/relationship paths.
S8 STOCK TRUTH — fresh complete stock evidence; semantic validation; zero/depleted/negative fail-safe.
S9 ELIGIBILITY — registration/PQR/origin/local-content/financial/experience; research only unless approved.
S10 CONVERSION — require all mandatory layers; otherwise preserve exact blocker.
S11 RED TEAM — attack every promotion edge and convert successful attacks to regressions.
S12 SOURCE/ADAPTER ROI — unique qualified evidence, primary recovery, false positives, latency/cost; promote/hold/kill.
S13 PERSISTENCE — GitHub+CI, Notion state, Drive evidence; read-back; supersession history.
S14 LEARNING — measure funnel drop-off, choose smallest improvement, version/test/rollback.
S15 ACTION GATE — prepare exact external payload; obtain exact approval; execute only approved target/version.
