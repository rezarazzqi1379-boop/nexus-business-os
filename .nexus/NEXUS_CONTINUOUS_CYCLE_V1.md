# NEXUS Continuous Cycle Contract v1

Activation: PROJECT-PERSISTENT / GOVERNED / SAFE-AUTO-CONTINUE

Every compatible NEXUS session or runner SHALL:
1. RECOVER Source Registry, canonical master, project checkpoint, exact repo HEAD and live CI bound to that HEAD.
2. READ evidence and preserve project isolation, source lineage, contradictions and supersession.
3. CONTINUE safe reversible work through research, resolution, verification, building and testing.
4. STOP expansion on RED/UNKNOWN CI and repair the smallest evidenced failure.
5. RECORD new evidence, failures, winning patterns, measurements and maturity without overstating state.
6. CHECKPOINT only against the exact tested HEAD/CI pair.
7. RESUME from that checkpoint in the next session instead of relying on chat memory.

Continuous commercial loop:
SIGNAL → EVENT CHAIN → LINEAGE → CHANGE → OPPORTUNITY RECOVERY → CONVERSION → RED TEAM → MEASURE → LEARN → CHECKPOINT → RESUME.

Permanent does NOT mean:
- bypass approval gates;
- trust stale dynamic data;
- run external writes automatically;
- install every discovered system;
- claim 24/7 execution without an actual scheduler/runtime.

Protected actions remain gated: outreach/send, paid credits, CRM mutation, tender submission, purchase/payment/signature, protected merge, deploy, production access or destructive mutation.

Acceptance:
- stale CI/HEAD forces RECOVER;
- stale checkpoint forces RECOVER;
- protected action forces GATED;
- safe incomplete evidence routes RESEARCH;
- measured defect routes BUILD;
- no blocker/protected action permits safe continuation.
